# Outgoing

Generated reports, dashboards, summaries, and artifacts produced by automation workflows.

## Purpose

Central output folder for all machine-generated documents and reports. Files here are ready for:
- Review and distribution
- Upload to Google Drive for archival
- Sharing with providers (doctors, accountants, etc.)
- Manual processing or editing

## What's Generated Here

### Document Processing Logs

**Inbox processing log:**
- `YYYY-MM-DD_process_log.txt` - Classification results for incoming/ files
- Lists all files processed, renamed, and moved
- Notes any errors or unclassifiable files

**Expiration scan:**
- `YYYY-MM-DD_expiration_report.html` - Upcoming document expirations
- IDs, visas, insurance, licenses expiring in next 90 days

**Generated by:**
- `personal/docs/process_personal_inbox.py`
- `personal/docs/scan_expirations.py`

**Destination:** 
- Logs: `G:\My Drive\Personal\Logs\`
- Expiration reports: review only, not archived

---

### Travel Sites

**Trip planning HTML:**
- `{trip-name}_itinerary.html` - Single-file trip site
- Real-time updates via Supabase
- Shareable link for family

**Generated by:** Manual creation + Supabase integration

**Source data:** Supabase ({trip}_* tables)

**Destination:** 
- `personal/travel/{trip-name}/`
- GitHub Pages: `https://fernandomartinez-de.github.io/personal/travel/{trip-name}/`

---

## Workflow

**Generated outputs (as needed):**
1. Document processing logs (on-demand via process_personal_inbox.py)
2. Expiration reports (on-demand via scan_expirations.py)
3. Trip planning documents (manual creation)
4. Any reports/visualizations generated by Claude

**Manual review (you):**
1. Check `vault/ops/outgoing/` for new files
2. Review accuracy
3. Move to Google Drive for archival (if needed)
4. Share with family/providers
5. Delete from outgoing/ after archival

**Automated cleanup:**
- Outgoing/ files older than 30 days auto-deleted (TBD)
- Archived copies in Google Drive remain indefinitely

## Archival Strategy

**Processing logs:**
- Keep 7 days in outgoing/docs/
- Archive to `G:\My Drive\Personal\Logs\` (optional)
- Expiration reports: review only, no archival needed

**Travel documents:**
- Keep in outgoing/travel/ during planning phase
- Move final itineraries to `G:\My Drive\Personal\Travel\{trip}/`
- Trip sites: Keep in repo under `personal/travel/{trip}/` (version controlled)
